=== CODES D'ERREUR API SIMDRAW ===

CODES D'ERREUR HTTP ET LEURS SIGNIFICATIONS :

400 - BAD REQUEST
- Requête malformée
- Paramètres manquants ou invalides
- Données d'entrée incorrectes

401 - UNAUTHORIZED  
- Authentification requise
- Token manquant ou invalide
- Credentials incorrects
- Session expirée

403 - FORBIDDEN
- Accès refusé
- Permissions insuffisantes
- Ressource interdite
- Action non autorisée pour cet utilisateur

404 - NOT FOUND
- Ressource non trouvée
- Endpoint inexistant
- Utilisateur ou données introuvables
- Route invalide

405 - METHOD NOT ALLOWED
- Méthode HTTP non autorisée pour cette route
- GET/POST/PUT/DELETE non supporté pour cet endpoint

406 - NOT ACCEPTABLE
- Format de réponse non acceptable
- Content-Type non supporté

408 - REQUEST TIMEOUT
- Délai de requête dépassé
- Timeout du client

409 - CONFLICT
- "Username already exists" - Nom d'utilisateur déjà pris
- "Email already exists" - Email déjà utilisé
- Conflit de données uniques
- État incohérent de la ressource

410 - GONE
- Ressource définitivement supprimée
- Endpoint déprécié et retiré

413 - PAYLOAD TOO LARGE
- Fichier ou données trop volumineux
- Limite de taille dépassée

415 - UNSUPPORTED MEDIA TYPE
- Type de média non supporté
- Format de fichier invalide

422 - UNPROCESSABLE ENTITY
- Erreurs de validation
- Format de données incorrect
- Contraintes métier non respectées
- Règles de validation échouées

429 - TOO MANY REQUESTS
- Limite de requêtes dépassée
- Rate limiting activé
- Trop de tentatives

=== CODES DE RÉPONSE HTTP API SIMDRAW ===

=== CODES DE SUCCÈS (2xx) ===

200 - OK
- Requête réussie
- Données retournées avec succès
- Opération standard complétée

201 - CREATED
- Ressource créée avec succès
- Nouvel utilisateur enregistré
- Nouvelle entité ajoutée à la base de données

202 - ACCEPTED
- Requête acceptée pour traitement
- Traitement asynchrone en cours
- Opération en attente

204 - NO CONTENT
- Requête réussie sans contenu à retourner
- Suppression effectuée
- Mise à jour sans données de retour

=== CODES DE REDIRECTION (3xx) ===

301 - MOVED PERMANENTLY
- Ressource déplacée définitivement
- Nouvelle URL permanente

302 - FOUND
- Redirection temporaire
- Ressource temporairement à une autre URL

304 - NOT MODIFIED
- Ressource non modifiée depuis la dernière requête
- Utilisation du cache autorisée

=== CODES D'ERREUR SERVEUR (5xx) ===

500 - INTERNAL SERVER ERROR
- "Database error" - Erreur de base de données
- Erreur serveur non prévue
- Problème technique interne
- Exception non gérée

501 - NOT IMPLEMENTED
- Fonctionnalité non implémentée
- Endpoint en développement

502 - BAD GATEWAY
- Erreur de passerelle
- Service externe indisponible

503 - SERVICE UNAVAILABLE
- Service temporairement indisponible
- Maintenance en cours
- Surcharge serveur

504 - GATEWAY TIMEOUT
- Timeout de la passerelle
- Service externe trop lent

=== MESSAGES D'ERREUR SPÉCIFIQUES ===

Validation (middlewares/validateUniqueDatas.ts) :
- "Username already exists" (409) - Le nom d'utilisateur existe déjà
- "Email already exists" (409) - L'email est déjà utilisé
- "Database error" (500) - Erreur lors de l'accès à la base de données

Authentification :
- "Invalid credentials" (401) - Identifiants incorrects
- "Token expired" (401) - Token d'authentification expiré
- "Access denied" (403) - Accès refusé
- "Unauthorized access" (401) - Accès non autorisé

Validation des données :
- "Missing required fields" (400) - Champs obligatoires manquants
- "Invalid format" (422) - Format de données invalide
- "Password too weak" (422) - Mot de passe trop faible
- "Invalid email format" (422) - Format d'email invalide

Ressources :
- "User not found" (404) - Utilisateur introuvable
- "Resource not found" (404) - Ressource introuvable
- "Drawing not found" (404) - Dessin non trouvé

Succès :
- "User created successfully" (201) - Utilisateur créé avec succès
- "Login successful" (200) - Connexion réussie
- "Data retrieved successfully" (200) - Données récupérées avec succès
- "Updated successfully" (200) - Mise à jour réussie
- "Deleted successfully" (204) - Suppression réussie
